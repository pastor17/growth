# 个人月度复盘模板

> 用途：工程师的个人成长复盘。月度的价值在于「回顾 → 提炼 → 调整」，
> 不是写工作总结，是对自己职业资产的盘点。
> 建议：每月最后一天花 30 分钟完成；季度末把月度复盘串起来看趋势。

## 本月概览

- 月份 / 年份：
- 一句话总结这个月（好事 / 难事 / 平淡）：

## 1. 目标回顾

月初定下的目标（技术 / 业务 / 学习 / 健康 / 关系）：

## 2. 关键事件（写事实，挑 3 件最值得记的）

1. _____________________________  → 我做了什么 / 结果如何
2. _____________________________  → 我做了什么 / 结果如何
3. _____________________________  → 我做了什么 / 结果如何

## 3. 做对了什么（要放大）

- 方法 / 习惯 / 决策，哪些有效？为什么有效？

## 4. 做错了什么（要修正）

- 哪些决定事后看是错的？代价是什么？
- 根因是什么？（信息不足 / 情绪 / 拖延 / 没问人）
- 下次遇到同类情况，我会怎么做？

## 5. 学到的东西（沉淀到知识体系）

## 6. 精力与状态
