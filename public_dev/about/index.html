👤 关于我

我是一名在大规模系统架构、互联网创业与技术人职业发展三条线上反复横跳过的工程师。这个站点记录我踩过的坑、做过的取舍，以及想明白的事——尽量写具体、写能用的，不写我自己都不会照着做的漂亮话。

三件事，我都在做

  • 做架构：主导过高并发系统的演进与改造，深知「最优解」往往不存在，只有权衡之后的「当下最好的解」。
  • 创过业：以技术合伙人的身份完整经历过从 0 到 1、从招人到现金流的周期，也坦然接受过失败——失败比成功教会我更多。
  • 带人成长：这些年帮不少技术人梳理过职业路径、评审过架构方案，发现多数困惑并非能力问题，而是「没人帮他们看清取舍」。

写给谁看

这个博客写给三类人：想把架构做扎实的后端工程师、想验证商业想法的创业者 / 独立开发者、正在做职业选择的技术人。如果你是其中一类，希望这里的文字能帮你少踩一个坑。

职业生涯时间线

  1. 早期

    后端工程师

    从业务开发起步，从「把功能做完」到「把系统做稳」，踩过单点、缓存雪崩、慢 SQL 等所有新手会踩的坑。

  2. 进阶

    架构师

    开始独立负责高并发系统的架构设计与演进，主导过 XX 万 QPS 量级的后端改造，从「选型」走向「取舍」与「复盘」。

  3. 创业

    互联网创业者 / 技术合伙人

    参与并创办过互联网项目，以技术合伙人身份经历从 0 到 MVP、从招人到现金流的完整周期，也经历过项目失败。

  4. 现在

    职业生涯顾问

    把架构、创业与成长的经验沉淀成体系化内容，帮助技术人做职业规划、技术方案与架构评审。
